# Security Policy

This repository contains prompt-engineering logic and examples, not application credentials.

Please do not submit:

- API keys
- access tokens
- passwords
- private certificates
- proprietary source code
- internal hostnames
- confidential API payloads
- private repository URLs

If you discover sensitive information accidentally committed to the repository, remove it from active use immediately, rotate the affected credential if applicable, and clean the Git history before public redistribution.
